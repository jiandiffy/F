# 白板崩溃回归检查

在项目根目录运行：

```sh
bash ui/desktop/build.sh --app=/tmp/F-regression.app
python3 ui/desktop/tests/run-whiteboard-tests.py
python3 ui/desktop/tests/run-queue-tests.py
python3 ui/desktop/tests/run-plugin-tests.py
python3 ui/desktop/tests/run-history-navigation-tests.py
python3 ui/desktop/tests/run-viewport-tests.py
python3 ui/desktop/tests/run-versions-tests.py
python3 ui/desktop/tests/run-project-mutation-tests.py
python3 ui/desktop/tests/run-update-tests.py
python3 ui/desktop/tests/run-project-stress-tests.py
```

F 内置 Agent 交付必须使用 `scripts/prepare-update.py`，该入口串行执行上述全部回归后才发布清单。

新增聚焦回归使用真实 WebKit 验证历史首次打开、活动父链、旧线性记录、目录符号链接与 Finder 别名、项目行加号。
视角套件将前端构建到临时目录，验证同项目两条对话的中心与缩放捕获、80次快速切换、窗口尺寸变化及新 WebKit 实例从磁盘恢复。
版本套件使用临时 Git 仓库和真实 AppKit，验证固定版本圆点、透明背景、水平滚动、多父关系、首次点击启用、简介来源、特殊文件名、删除/二进制/大文件边界及固定 blob 的只读预览。
项目迁移套件使用临时目录与隔离偏好设置，检查 Rename/Delete 菜单、入口隐藏与恢复、文件夹和关联存储迁移、冲突拒绝与失败回滚。不得使用用户真实项目作为迁移夹具。
Agent 大版本策略由 `runtime/harness/tests/versions*.test.mjs` 验证。GitHub权限查询可用隔离runner，快照祖先隔离用真实本机Git和临时bare仓库验证；这不等同真实GitHub联网发布验收。

需要 macOS 图形登录会话和 Swift 命令行工具。构建脚本会在缺少全局 npm 时使用
`runtime/node/bin` 中自带的 Node。测试直接编译当前 `main.swift`，只替换应用入口，
使用临时项目和单独的应用标识，不访问真实会话或白板。

检查内容：

- JSON 字符串、布尔值、数字、空值、嵌套对象和中文/转义字符能往返，非法值被拒绝。
- 真实 WebKit 加载打包后的白板，完成 ready 握手并加载场景。
- 明暗主题切换、带中文和换行的忙碌提示、清除提示。
- 原生输入框转发指令，忙碌时按序排队；画板与项目对话共用模型、思考程度及较短的输入框尺寸。
- 900 / 520 / 220 点宽度下的工具栏边界，后序工具收纳及素材库展开。
- 顶部整体居中，缩放和历史控件位于绘图工具右侧；窄窗口只收纳绘图工具，右侧控件保持固定尺寸。
- 放大与重置缩放作用到真实画布。
- 顶部菜单打开导出、清空确认，弹窗期间隐藏输入框和工具栏，关闭后恢复。
- 模型服务报错与中止后解除忙碌状态，余额不足等错误会显示给用户。
- 使用临时项目验证统一存储、切换前保存、项目间隔离、图片恢复和旧路径的一次性迁移。
- 检查 Agent 重连后的项目目录、画板目录及保存位置变更后的配置失效。
- 从真实 WebKit 导出 PNG（长边 1024 / 2048 / 4096）、JPG、SVG、PDF 图像数据，验证图片元素、编码和像素尺寸。
- 用 PDFKit 渲染原生生成的 PDF，验证页面比例、页数和无额外页边距。

队列检查使用独立的临时 RPC 子进程，不请求真实模型或写入真实对话：

- Agent 忙碌时，项目和画板输入的 Enter 都排入同一队列，逐条执行。
- 点击淡灰色 ↳ 优先执行该条；验证 abort 确认与任务结束两种先后顺序，以及连续插入时不丢失其他条目。
- Ctrl+C 在 F 的输入框、画板、终端及设置窗口中均可中断正在执行的 Agent。
- 第一次 Ctrl+C 保留并暂停未发送队列，空白 Enter 可继续；暂停时再次 Ctrl+C 终止任务并清空队列，包括 abort 尚未返回的情况。验证启动阶段取消、异常后恢复和无响应中断的兜底停止。
- 点击队列文字原位编辑，Enter 保存、Esc 取消、空白修改不覆盖；编辑时等待确认再发送下一条。右侧淡灰色 × 只删除该条，其他顺序、编号和画板上下文保持不变；新增排队项不打断编辑。
- 队列超过四行时可以滚动查看，每条的执行按钮始终可访问。

插件与 SSH 回归使用临时密钥、独立 known_hosts 和监听 127.0.0.1 的临时 sshd；
不会连接用户 config 中的主机，也不会写入真实 SSH 配置。

- 插件注册、底部栏选择、激活/隐藏、项目更新和统一退出。
- 停靠区多进程：同一模块创建多个独立实例、切换标签、默认名称编号、标签原位改名（Enter 保存、
  Esc 放弃、空白不覆盖）、关闭单个/全部进程，以及已有进程时重新展开底栏直接进入左右分隔而不再显示选择页。
- 拖动灰线调整停靠区宽度；side agent 每次请求都读取主对话最新上下文。
- side agent 正在执行或还有排队消息时阻止更新重启，队列排空后恢复。
- side agent 注册为底栏进程，默认名称 `side agent`，与主对话共享会话专属画板目录。
- SSH config 的多个别名、Include、引号、通配符与循环引用；非法主机输入被拒绝。
- 真实本机 PTY 的工作目录与 `F_BOARD_DIR` 和当前对话的画板目录一致（包含 macOS 临时目录别名）。
- 手动密码仅在 PTY 认证提示后发送，随后清空，且不会回显。
- 真实 OpenSSH ControlMaster 连接；远程文件名含中文、引号、空格或换行时仍可读取。
- 同一端点和项目下的多个 SSH 面板拥有各自真实运行的终端视图和远程 shell，互不挪动，
  且都通过 `-S` 复用同一个 ControlMaster；额外进程不新建 master。
- 新建/切换项目前同时询问注册表 SSH 与停靠区 SSH 进程的未保存编辑。
- 拖入文件夹：窗口只接受真实存在的文件夹（文件、非本地项和不存在的目录被忽略），Dock
  入口与窗口入口一致；新对话使用独立画板且会话为空，左侧“项目”在首句话写入会话文件后
  才出现该对话。
- 远程文本原子保存与权限保留；并发修改、二进制、大文件和符号链接写入受保护。
- 原生远程编辑器保存与脏状态；连接断开后不另起登录。

远程项目追加覆盖：

- 单框地址解析（用户名/端口可省略、IPv6）、Enter 认证与实际免密主机探测。
- 端点与远程目录共同生成稳定项目标识；不同主机隔离画板、同端点别名复用画板。
- 已登录会话进入项目候选列表，未验证的主机不能绕过认证进入。
- 真实 SSH 下验证 Agent 的 read/write/edit/bash/ls/find/grep、远程 cwd 和本机代理目录不落文件。
- AbortSignal 取消远程进程与子进程；连接失效后即使同路径本机文件存在也不能回退读取。
- Agent 白板工具仍写入对应的集中存储，而不是远程项目目录。- PiRPC 启动使用当前认证套接字、远程目录和统一画板环境；项目终端单独复用通道进入远程目录。

插件开关与应用规范追加覆盖：

- 底栏展开先选择；选择后工作区左右分隔，左侧主体内容、右侧停靠区，再次展开直接恢复。
- F/plugin 勾选状态、持久化及禁用后菜单和侧栏移除。
- 画板禁用时停止轮询；关闭期间切换项目，重新启用恢复最新项目且不改写画板数据。
- 临时独立应用仅注册一次，即可出现在应用栏、应用菜单并接收设置命令，不接收项目切换。
- 项目插件的数据目录隔离；禁用画板后不注册 Agent 画板工具。
- 主界面五个应用（画板、浏览器、版本、Daily Paper、Gmail）共用滚动容器：对话框占用高度成为文档末尾的滚动余量，被盖住的底部可以拉到对话框上方；窗口高度不足时内容仍按最低高度排版并可上下滚动；回到主对话后隐藏容器并清除余量。

终端清屏追加覆盖：

- ANSI `CSI 2J`、`CSI 3J` 与 clear 常用的光标归位组合，清除文字和旧滚动区域。
- 将清屏转义序列与中文 UTF-8 字节逐字节送入，验证 PTY/SSH 数据分段不会破坏清屏或中文。
- 跨分段的 OSC 标题序列和原有清行功能。
- 真实本机 shell 与临时 SSH 终端执行 `clear` 后，旧标记消失、新输出和提示符正常显示。

完整终端与安全自维护追加覆盖：

- 内置 xterm.js VT 渲染器通过 PTY/SSH 接入，验证方向键、行中插入、Backspace、Delete、历史上下键、Tab 文件补全、中文与 clear。
- 更新协调器等待发布更新的对话和停靠区空闲；其他对话先原子保存中断历史，再等待 abort 确认与 agent_settled，未安全停止则取消重启。恢复原 session、未完成任务、队列顺序、画板指令、手动暂停、模型/思考程度及两个输入草稿，并显示更新公告。
- 原生队列回归验证中断记录可从磁盘解码、恢复就绪前不派发、单次续接、原会话重连、启动默认模型不覆盖已保存选择、模型切换事件不覆盖思考设置、模型/思考设置失败不派发且保留任务、最终 stop 先于快照时不重发、停止超时后迟到 abort 成功/失败及 settle 不强杀或丢续接、用户暂停不被自动解除、写盘失败不发 abort，以及更新不使用两秒强杀兜底。模型内部思考和任意 shell 进程状态不属于序列化承诺。
- 独立安装器校验制品、签名与应用身份；不替换运行中的 F；保留 F.app 外层目录并备份旧版本；启动失败恢复旧 Contents。
- 内置 Agent 的就地覆盖、--fresh 和 --relaunch 被阻止；并发构建有锁。
- 安装/回滚测试使用临时模拟 bundle；原生 AppKit 退出测试验证异步保存回调不会被主队列内的退出等待卡住。真实自更新由 prepare-update.py 提交后通过启动就绪标记确认。

多项目有界压力回归（`run-project-stress-tests.py`）：

- 6 个真实独立 RPC 子进程模拟 Agent，不调用付费模型：6 条持有请求与 301 条排队 prompt，核对每个项目恰好执行一次并保持顺序。
- 500 次项目/画板快速切换，含 A→B→A，核对最后请求胜出、原画板内容不串写、后台队列回调不会改变前台输入框。
- AIOS 和 agent 两条对话刻意使用相同 cwd，验证同时后台运行、各自会话专属 F_BOARD_DIR；200 次真实历史选择→画板切换显示正确图形，更新后两条对话及画板草稿不合并。
- 会话文件到 boardID 的持久绑定、同目录不同会话隔离；旧目录画板仅认领迁移一次，已有会话场景优先，新对话保持空白。
- 原生 ↑↓ 输入历史、草稿恢复、多行光标移动、中文输入法组合；5000 次记录、200 条容量上限、超大粘贴、重建恢复与项目隔离。
- 更新保存/恢复 6 个项目的模型及草稿；后台项目发起更新时，仅原请求对话展示公告，同项目其他对话及前台其他项目不展示。

这些是有限负载下的确定性回归，不代表对任意模型提供商或无限并发的稳定性承诺。

# 浏览器回归

`python3 ui/desktop/tests/run-browser-tests.py` 使用隔离网页、Cookie和本机IPC夹具验证浏览器插件；不读取真实 Chrome 密码或 Cookie。`runtime/harness/tests/browser.test.mjs` 验证传输与 Chrome 桥接安装配置。完整发布自动运行这两套检查。

浏览器新增真实表单 POST 登录、跨标签/窗口会话、前进后退、window.open 的 opener 回传与关闭、
target=_blank、6轮连接中断与恢复、网页进程终止、240次切换和窄窗口检查。
另启动两次独立测试进程，在随机标识的持久 WebKit profile 验证 Cookie/localStorage 跨进程恢复；
测试结束只清除该测试 profile 的网站数据，不触及用户登录。
队列套件通过独立 RPC 子进程注入断网、额度耗尽、上下文超限、认证 token 过期、限流和输出预算耗尽，
检查队列暂停、不自动重发、待发送内容保留及手动恢复。这些是故障模拟，不消耗用户额度来制造真实欠费。
